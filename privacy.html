Privacy

Image Compressor is a static browser utility. Image bytes stay on your device and are not uploaded to our servers.

Local processing

When you choose an image, it is read and compressed by browser APIs on this device. There is no account, cloud history, backend image store, or server-side image processing in the MVP.

Analytics

Product analytics are not part of this phase. Future analytics must use coarse, allowlisted events only and must not include file names, file bytes, blob URLs, image hashes, EXIF data, or raw error messages.

Browser memory and cache

Your browser controls memory, temporary blob storage, and cache behavior. The service does not intentionally store your images, but the browser may manage temporary local resources while the page is open.

Normal site delivery

Loading the website can still create normal CDN or hosting logs, such as IP address, user agent, path, and timestamp. Those delivery logs are separate from image processing and should not contain your image file.
